# M3 CSS Decisions

## Design Direction

I chose an editorial and artistic style inspired by scrapbook and collage layouts.

## My CSS Decisions

I used a light blue background to make the portfolio feel calm and creative. I used dark blue for the header and footer so the text remains easy to read.

I used yellow for the navigation links and orange for buttons and hover effects. These colors create contrast and make the important interactive elements noticeable.

I used white sections with borders and shadows to separate the content from the background.

## Accessibility Decisions

I added hover styles for links and buttons. I also added focus outlines so keyboard users can see which element is selected.

I used labels for the form inputs and table headings for the skills table.

## Responsive Decision

I added a media query for screens smaller than 600px. The main content becomes wider on small screens, and the form fields stay inside the page.

I tested the Contact page at 320px wide. The content still fits and is readable.

## AI CSS Comparison

The AI stylesheet was saved separately as `ai-style.css`. It was not linked to the HTML pages because my own stylesheet is the one used by the website.

I compared both stylesheets based on colors, spacing, layout, navigation, forms, tables, hover states, and responsive behavior.

## Final Choice

I kept my own stylesheet as the final stylesheet because it is simple, easy to understand, and matches my chosen light blue editorial style.
